# Curvy Blast

Un jeu ludique pour apprendre l'importance des fonctions dans les mathématiques !

## Installation

Aucune installation n'est requise. Lancez simplement le fichier curvy-blast.exe pour jouer au jeu !

Le code source est également fourni dans cette [archive](https://drive.google.com/file/d/17z38UXQw0z4mE_oNzf5mQ_4Qirqqh9d0/view?usp=sharing) ou accessible sur le [Repo git du projet](https://git.iut-orsay.fr/kzoh/curvy-blast.git) (accessible à M. Ferey).
